# SmartStreet Guinea

A solar lighting and weather-awareness totem for the neighbourhoods of Guinea.

## What it is
SmartStreet is a single off-grid solar totem that brings five things to a
neighbourhood:
- All-night street light
- A visual + sound warning system for heavy rain and flooding
- A natural meeting point after dark
- A daily, public marker that climate change is being taken seriously here

## Why
- ~51% of Guinea's population has access to electricity (25.7% rural)
- 30+ deaths from flooding in Conakry in June–August 2025 alone
- No visible street-level warning system currently exists in informal settlements

## What's in this repo
- `docs/`- project narrative, briefs, supporting documents
- `design/`- totem architecture and visual design
- `research/`- flooding data, electricity access stats, field notes
- `generator/`- Node.js script that builds the project narrative deck
